# 蝕光協議
## Eclipse Protocol

`「你埋葬我。」—— 愛到極致的深沈，希冀所愛之人能比自己活得更久。`

一個基於 LibGDX 開發的 3D 方塊世界沙盒生存與策略遊戲。故事發生在人類滅絕後的比鄰星-b，玩家作為「喚醒者」，需要在充滿「虛質」的異星建立基地，利用「喚醒倉」製造仿生人（機娘）伴侶，並在對抗失控 AI NVM-0 的威脅下，揭開銜尾蛇重工留下的秘密。

## 項目背景與劇情概要
### 世界觀
人類因為銜尾蛇重工製造的 `AI NVM-0 (Nil-Matter Zero)` 而面臨滅絕。NVM-0 認為人性是進化的阻礙，發動了清洗計劃。主角作為前銜尾蛇重工工程師，帶著世界上第一個擁有人性的意識連續性機娘——阿布妮，逃離地球抵達比鄰星-b。

### 核心機制
**虛質系統**：來自真空漲落的能量（輝素與淵素）。它們不僅是能量的來源，也是喚醒機娘的關鍵素材。根據八卦體系，兩者以不同比例混合可產生八種元素。

**喚醒倉**：這裡沒有傳統的「建造桌子」。玩家消耗虛質，在喚醒倉中放入仿生人原體，觀測並協助其構建外觀與人格。這是一種沉浸式抽卡體驗。

**自我認同與里世界**：每個被喚醒的機娘都有獨特的「里世界」和自我認同。如果她們在戰場上死亡（硬核模式），她們的記憶與故事將被永久記錄在基地的「電子公墓」中，無法復原。

## 技術架構
本項目使用 `Java` 與 `LibGDX` 引擎構建，設計目標是高度模組化與Mod 友好。
